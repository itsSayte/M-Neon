## 📖 About

M-Neon is a management platform for Minecraft servers created as a study project.

The goal of M-Neon is to provide a centralized interface that allows administrators to:

- 🎮 Manage Minecraft servers
- 📊 Monitor server status and performance
- 👥 Manage users and permissions
- 📜 Access logs and server information
- ⚙️ Simplify administration tasks

---

## ✨ Features

- Modern web interface
- Server monitoring
- User management
- Permission system
- Docker deployment
- Easy configuration
